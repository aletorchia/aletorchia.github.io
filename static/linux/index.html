./commands/aggiornare-il-sistema

Aggiornare il sistema

Aggiorna tutti i pacchetti installati:

$sudo pacman -Syu
$paru -Syu
$sudo cachyos-rate-mirrors

./commands/installare-e-rimuovere-programmi

Installare e rimuovere programmi

Installare un programma dai repository ufficiali:

$sudo pacman -S nome_pacchetto
$sudo pacman -S fastfetch
$sudo pacman -R nome_pacchetto
$sudo pacman -Rns nome_pacchetto

./commands/pulizia-del-sistema

Pulizia del sistema

Pulire la cache dei pacchetti vecchi:

$sudo pacman -Sc
$sudo pacman -Scc
$sudo pacman -Rns $(pacman -Qtdq)

./commands/informazioni-sul-sistema

Informazioni sul sistema

Mostrare informazioni rapide del PC:

$fastfetch
$uname -r
$hostnamectl
$lspci | grep -E "VGA|3D"
